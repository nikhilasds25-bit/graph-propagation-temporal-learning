# Source data not included

No raw tweets or tweet text are included in this package. Reproduction requires the project owner’s authorized copies of data/raw/master_tweets.csv and network_edges.csv, plus the protected processed/model-output inputs listed in input_file_hashes.txt. The project inputs do not establish a public download URL, dataset DOI or collection licence; request provenance and lawful access instructions from the project owner, rather than assuming availability or using an invented source. Native tweet IDs/reply metadata are not recoverable from the supplied schema.
