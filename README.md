# Graph Propagation and Temporal Learning

Reproducible research assets for **Graph-Based Information Propagation and Temporal Learning in a Directed Indian Political Twitter Network**.

This repository contains manuscript source, reproducibility notes, analysis scripts/results that are safe to publish, and supporting material used in the project.

## Scope

The project studies:
- directed network structure and reachability,
- reconstructed timestamped interactions,
- time-respecting paths,
- stochastic propagation and competition sensitivity,
- leakage-controlled weekly forecasting,
- matched node-only and graph-model comparisons.

## Data policy

Raw tweet text and raw account-level source files are intentionally **not** committed here. The repository keeps hashes, derived aggregates, scripts, figures, and manuscript material instead.
